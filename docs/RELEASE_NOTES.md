# Асық ату — v1.0.0-submission

## Игра

- Бросок сақа «как из рогатки» (мышь и палец), плоская детерминированная физика Matter.js, псевдообъём (тени, блики, параллакс).
- Обучение, 2 главы по 5 испытаний, особые асыки (золотой, тяжёлый) и каменные блоки, звёзды и par.
- Режимы: вдвоём на одном экране, дуэль с ботом (3 уровня), бесконечный, ежедневное испытание.
- Редактор своих испытаний и вызов другу по ссылке (полной или короткой через облако).
- Достижения, история, статистика; косметический магазин и тестовый набор «Той-Pro».
- RU / ҚАЗ / EN, «Продолжить» после перезагрузки.

## Инфраструктура

- CI на GitHub Actions: типы, линтер, формат, тесты с покрытием, сборка, бюджет размера, smoke в браузере, gitleaks.
- Post-deploy smoke и плановая проверка доступности; SHA сборки в «О приложении».
- Заголовки безопасности, CSP в режиме Report-Only.

## Облако (включается переменными окружения)

- Supabase: гость в один клик, аккаунт email+пароль, синхронизация прогресса между устройствами, рейтинг, короткие ссылки на вызовы, удаление аккаунта.
- RLS на всех таблицах, запись в рейтинг только через серверную функцию с проверкой пределов.
