# Дизайн: «казахский орнамент + тёплое золото + глубина»

Ветка `feat/design-polish` (от `feat/desktop-layout`). Физика, правила, хитбоксы и баланс не менялись. Всё ниже касается только внешнего вида, звука и интерфейса.

Коммиты можно откатывать по отдельности:

1. `Design 1/5` — ассеты и отрисовка моделей.
2. `Design 2/5` — дизайн-система и компоненты.
3. `Design 3/5` — «сочность», звук, качество.
4. `Design 4/5` — вес ассетов (WebP), проверка читаемости, скриншоты, документация.

## Ассеты

Пак лежит в `public/assets/{saka,asyk,props,ui}`, размеры по README пака: сақа 168×102, асык 132×78 (@3x от 44×26), блок 216×192, иконки до 128 px, эмблема до 256 px.

- **Имена были перепутаны.** В присланных файлах имена не совпадали с содержимым (например, в `ui_lock.png` лежала эмблема). Файлы разобраны по содержимому. Исходники вынесены из репозитория в соседнюю папку `asyk_atu_assets_raw/`.
- **WebP для загрузки.** Игра грузит WebP-копии (`node scripts/webp-assets.ts`): 369 КБ вместо 1580 КБ PNG. PNG остаются в репозитории исходниками.
- **Что грузится сразу.** В preload сцены попадает только текущее оформление: надетая сақа, набор асыков, золотые и тяжёлые асыки, блоки, кайма кона и декор текущей карты. Остальные скины подгружаются при надевании. Иконки интерфейса и шрифты подгружаются сразу после старта, поэтому без сети интерфейс остаётся целым.
- **Хитбоксы не менялись.** Спрайт вписывается в размер тела из `config.ts`. Картинка блока 72×64 вписана в хитбокс 40×40 (+12 %).
- **Без картинки игра тоже работает.** Если файл не загрузился, остаётся процедурная отрисовка.
- **Каталог магазина.** jade и onyx (набор «Той-Pro») нарисованы как «Айдаһар» и «Неон». В магазин добавлены сақа «Бүркіт», «Барыс», «Тұлпар», «Лава» и асыки «Ағаш».
- **Карт в паке нет** (см. README пака: исходники квадратные). Поэтому поле процедурное, поверх него — декор из пака.

## Дизайн-система

`src/styles/tokens.css`, `src/ui/tokens.ts` (для canvas).

- **Палитра.** Фон — ночной индиго (`--c-night-*`), акцент — тёплое золото (`--c-gold-*`), вторичные — терракота и бирюза, текст — кремовый. Контраст (WCAG): кремовый текст на индиго — 13–15:1, приглушённый текст — 8,4:1, тёмный текст на золотой кнопке — 7,7–11,5:1, белый текст на бирюзовой кнопке — не меньше 5:1.
- **Шрифты.** Два семейства, оба подключены локально через `@fontsource` без внешних запросов: Montserrat Alternates для заголовков и Nunito для текста. Подмножество `cyrillic-ext` содержит казахские ә ғ қ ң ө ұ ү һ і.
- **Шкалы.** Размеры 12/14/16/20/28/40 (в em: интерфейс масштабируется вместе с полем). Отступы 4/8/12/16/24. Радиусы sm/md/lg/pill. Три уровня тени с индиго-оттенком и золотое свечение для выбранного. Движение: 120/200/320 мс, общие кривые `--ease-out` и `--ease-spring`.
- **Компоненты** (`src/ui/theme.css`):
  - **Кнопки** четырёх видов:
    - primary — золотой градиент, внутренний блик, глубокая тень;
    - secondary — тёмное стекло с золотой рамкой;
    - ghost;
    - danger.

    Состояния: hover, active (проседание на 2 px), focus-visible, disabled, loading. Зона нажатия не меньше 44×44.

  - **Чипы, вкладки, переключатели, ползунок громкости, прогресс, тосты.**
  - **Панели и модалки** — стекло с размытием (на среднем и низком качестве без размытия), орнамент по углам, появление 0.96 → 1 за 200 мс.
  - **Карточки** уровней, режимов, магазина и достижений: выбранная — с золотым свечением, закрытая — с `ui_lock`. Редкость показана цветом, формой-ромбом и подписью, а не только цветом.
- **Иконки из пака** заменили эмодзи: монета, звёзды (полная и пустая отличаются формой), замок, сердца попыток, кубок, молния, шестерёнка. Эмблема есть в меню, фавиконке и картинке для соцсетей 1200×630 (`node scripts/brand-images.ts`).

## Модели и поле

- **Сақа и асыки:**
  - спрайт, мягкая тень, контактная тень, блик сверху-слева;
  - подпрыгивание по `z` и навес — как было;
  - 3 варианта рисунка на набор, выбор по id тела;
  - вращение по угловой скорости физики.
- **Ореол по силуэту.** Цвет берётся по яркости земли: тёмный на светлой карте, светлый на ночной. Ореол есть только на «Высоком» качестве.
- **Золотой асык.** Блик пробегает раз в ~3,5 с (кадры запечены, при reduced motion выключено).
- **Кон.** Кайма «оюлы» из пака, её внешний край совпадает с границей «выбит», поверх неё рисуется чёткая линия. Когда асык пересекает кромку, в этой точке расходится бирюзовая волна.
- **Декор по теме.** Камни, ветки, трава, цветы, снег лежат только по краям: не в кону, не у линии броска.

## «Сочность»

- **Частицы.** Пул на 150 штук, обновление покадрово без аллокаций.
- **Удар сақа.** Вспышка и волна цвета скина плюс частицы скина: дракон — искры, неон — неоновый след, тулпар, золото и барс — свечение, лава — угольки. В полёте за сақа тянется след того же цвета.
- **Сильный удар.** Хитстоп 50 мс (замирает только экран, шаги симуляции те же) и тряска камеры до 4 px.
  - Тяжёлый асык: тряска сильнее и глухой низкий звук.
  - Блок: пыль.
  - Золотой: искры и звук блеска.
- **Итог раунда.** Звёзды загораются по очереди со звуком и искрами, очки и тиын «набегают».
- **Переходы между экранами** — 200 мс.
- **Отключение.** Всё выключается при `prefers-reduced-motion` и на низком качестве.
- **Звук** (WebAudio, первый звук — только после жеста пользователя). Есть клик, натяжение рогатки, бросок, удар, тяжёлый удар, выбивание, блеск золота, звёзды, монеты, победа, поражение. В настройках — громкость 0–100 % и отдельный выключатель звука.

## Качество

| Уровень | Что включено                                                                |
| ------- | --------------------------------------------------------------------------- |
| Высокое | мягкие тени, ореол, все частицы, размытие панелей                           |
| Среднее | мягкие тени и частицы; без ореола и размытия                                |
| Низкое  | простые тени; без параллакса, подпрыгивания, искр, следа и размытия         |
| Авто    | начинает с «Высокого», понижает на ступень, если средний FPS за 3 с ниже 45 |

## Проверка

- `node scripts/design-shots.ts --out docs/design/after` — 6 экранов (меню, уровни, игра, итог, магазин, настройки) на 390×844, 768×1024, 1366×768 и 1920×1080. «До» — в `docs/design/before`.
- `node scripts/contact-sheet.ts` — контактные листы «до / после»: `docs/design/contact-<размер>.jpg`.
- `node scripts/readability.ts` — матрица читаемости «карта × набор асыков × сақа» на уровне с обычными, золотыми асыками и блоками: `docs/design/readability.png`. Все три набора читаются на всех четырёх картах.

## Что упрощено

- **Анимация монет.** Монеты не летят к счётчику, счётчик тиын «набегает».
- **Магазин.** Превью скина слегка покачивается, но тест-броска в магазине нет.
- **Размытие в движении.** Для летящего асыка нет растяжения по скорости, его заменяет след сақа.
- **Карты.** Выбор карты — через магазин (площадки), отдельной ленты выбора нет.
- **Ассеты.** Атласов текстур нет: картинок немного (до 20 на первый экран), и они маленькие. `@3x` не разделяется по DPR, потому что пак дан одним размером (@3x).

## Производительность

Первый экран (меню, телефон 390×844, локальная сборка) весит **807 КБ** при бюджете 1,5 МБ:

| Что                           | КБ  |
| ----------------------------- | --- |
| JS (Phaser + игра)            | 388 |
| Шрифты (используемые subsets) | 171 |
| Картинки дизайна (WebP)       | 236 |
| CSS                           | 11  |

- Размер JS после дизайна: 387,6 КБ gzip (лимит 428 КБ). Модуль 3D: 139 КБ, грузится лениво.
- Lighthouse 12 в этом окружении не смог разобрать трассировку браузера Playwright. Поэтому замер сделан вручную: медленный 4G (1,6 Мбит/с, RTT 150 мс) и замедление CPU ×4, как в мобильном профиле Lighthouse. Результат: FCP около 0,5–0,7 с, меню интерактивно через 11 с. Цифра сильно завышена: 3D и WebGL здесь рисуются программно (SwiftShader) на замедленном CPU. Оценку LCP ≤ 2,5 с и FPS нужно снимать на реальном телефоне. Основную часть веса по-прежнему даёт Phaser, он был и до дизайна.
- В игре ограничение частиц (150), запечённые текстуры и автопонижение качества по FPS держат нагрузку в рамках. На слабой графике размытие панелей выключается.
