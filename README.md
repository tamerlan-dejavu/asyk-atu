# Асық ату

Современная цифровая версия традиционной казахской игры на меткость **«асық ату»** — 2D-игра для браузера, управление мышью и пальцем, без установки.

**Играть:** `ССЫЛКА_НА_ДЕПЛОЙ` ← _автор вставляет ссылку Vercel после деплоя_  
**Репозиторий:** https://github.com/tamerlan-dejavu/asyk-atu

## 1. Что это за игра и для кого

Игрок берёт **сақа** (тяжёлую биту), оттягивает её назад, как рогатку, отпускает — и старается выбить **асыки** (бараньи косточки) за границу **кона**. В игре есть обучение, пять испытаний с нарастающей сложностью, рекорды, режим «вдвоём» на одном экране и ежедневное испытание.

Аудитория: школьники, студенты и семьи; знакомство с традиционной игрой в современном формате — правила понятны за один бросок, партия занимает 2–3 минуты.

## 2. Правила и как они адаптированы

- **Поле** — вид сверху, портретное. Вверху кон (круг), в нём стоят асыки; внизу линия броска, с которой всегда стартует сақа.
- **Ход:** зажми в нижней трети поля → потяни назад (направление и сила) → отпусти. Физика доигрывает до полной остановки (или до тайм-аута 7 с), затем считаются очки.
- **«Выбит»:** асык выбит, когда его **центр** вышел за границу кона. Засчитывается один раз, навсегда (повторных начислений нет).
- **Очки за бросок:** `10·k + 5·(k−1)` при k ≥ 1 (1 → 10, 2 → 25, 3 → 40). В кампании +10 за каждую неиспользованную попытку при чистом коне.
- **Звёзды:** 3★ — очистить за *par* бросков или меньше, 2★ — за *par + 1*, 1★ — за любое число доступных бросков.
- **Вдвоём (один экран):** общее поле, по 6 бросков у каждого, броски чередуются, очки получает тот, кто выбил асык; побеждает набравший больше, при равенстве — ничья.

**Что упрощено по сравнению с настоящей игрой и почему:** в настоящей игре есть разные виды бросков и правила пересчёта позиций («алшы», «тайкы» и др.) — для короткой браузерной партии оставлена одна понятная механика «выбить из кона». Реальное трение и объём заменены плоской физикой (вид сверху) — прицеливание остаётся точным и одинаковым на всех устройствах.

## 3. Что я добавил от себя

- Звёзды и *par* для каждого испытания; открытие уровней по прогрессу.
- Ежедневное испытание: расстановка генерируется из даты (`mulberry32`), одинакова у всех в этот день; лучший результат хранится по дате.
- Локализация RU / ҚАЗ / EN (переключатель в меню).
- Псевдообъёмная подача поверх плоской физики: мягкие тени с единым источником света, блики и фаска на асыках и сақа, вдавленный кон, подпрыгивание при ударе, параллакс из трёх слоёв фона, «камерный толчок» при попадании. Всё отключается настройкой «Качество» и `prefers-reduced-motion` и **не влияет** на физику и очки (проверено тестом `render-isolation`).
- Управление с клавиатуры (стрелки — направление, пробел удерживать — сила, отпустить — бросок), Esc — пауза.
- Тренировочный режим (бесконечные попытки, рекорды не пишутся), пауза, автопауза при сворачивании вкладки.
- Синтезированный звук (Web Audio) — без файлов и лицензий.

## 4. Как запустить

```bash
npm i
npm run dev      # dev-сервер Vite
npm run build    # проверка типов + сборка в dist/
npm test         # Vitest: правила, уровни, сохранения, физика
npm run e2e      # Playwright smoke-тест (нужен: npx playwright install chromium)
```

Деплой: репозиторий импортируется в Vercel (Framework preset — Vite; build `npm run build`, output `dist`). Запасной вариант — Netlify с теми же настройками.

## 5. Технологии

| Технология | Зачем |
|---|---|
| TypeScript 5 (strict) | типы ловят ошибки в игровом состоянии, код проще объяснять |
| Vite | мгновенный dev-сервер, `vite build` → статика |
| Phaser 3 | игровой цикл, масштабирование (FIT), отрисовка без внешних ассетов |
| Matter.js (встроен в Phaser) | столкновения полигонов, трение, отскок — физику с нуля писать не пришлось |
| HTML + CSS поверх canvas | меню, HUD, модалки: быстро стилизуются, текст масштабируется |
| `localStorage` (обёртка с версией схемы) | рекорды и прогресс без бэкенда |
| Web Audio API | звук синтезируется в коде |
| Vitest + Playwright | тесты логики и один smoke-тест на реальном рендере |

Архитектура: правила (`rules/`, `levels/`) и физический мир (`physics/sim.ts`) — чистый TypeScript без Phaser и DOM; Phaser только рисует и передаёт ввод; UI общается с игрой через типизированный `EventBus`.

## 7. Заимствованное

- [Phaser](https://phaser.io) — MIT; [Matter.js](https://brm.io/matter-js/) (встроен в Phaser) — MIT.
- Шрифты — системные, ничего не подключается. Сторонних ассетов нет: графика рисуется кодом (Canvas 2D / SVG), звук синтезируется.
- Дополнительных зависимостей сверх `phaser`, `typescript`, `vite`, `vitest`, `@playwright/test` нет.

## 8. Известные ограничения

- Игра рассчитана на портретную ориентацию; в горизонтальной на телефоне показывается просьба повернуть устройство.
- Казахские тексты требуют проверки носителем языка (помечены `// verify: native speaker`).
- Гироскоп для параллакса и карточки культуры не реализованы; ИИ-противник, сетевой мультиплеер и бэкенд вне рамок MVP.
- Соотношение сторон поля фиксировано 2:3, на очень вытянутых экранах остаются декоративные поля сверху и снизу.

## Дорожная карта

Бэкенд и авторизация для общего рейтинга, мультиплеер по ссылке, редактор расстановок, косметические наборы (оформление асыков и площадок) — без влияния на результат матча.
