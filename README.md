# Асық ату

Современная цифровая версия традиционной казахской игры на меткость **«асық ату»** — 2D-игра для браузера, управление мышью и пальцем, без установки и без регистрации.

**Играть:** `ССЫЛКА_НА_ДЕПЛОЙ` ← _автор вставляет ссылку Vercel после деплоя_  
**Репозиторий:** https://github.com/tamerlan-dejavu/asyk-atu

## 1. Что это за игра и для кого

Игрок берёт **сақа** (тяжёлую биту), оттягивает её назад, как рогатку, отпускает — и старается выбить **асыки** (бараньи косточки) за границу **кона**. В игре: обучение, две главы по 5 испытаний с нарастающей сложностью, особые асыки и каменные препятствия, игра вдвоём на одном экране, дуэль с ботом, бесконечный режим, ежедневное испытание, **редактор своих испытаний с вызовом друга по ссылке**, достижения, статистика и косметический магазин.

Аудитория: школьники, студенты и семьи; знакомство с традиционной игрой в современном формате — правила понятны за один бросок, партия занимает 2–3 минуты.

## 2. Правила и как они адаптированы

- **Поле** — вид сверху, портретное. Вверху кон (круг), в нём стоят асыки; внизу линия броска, с которой всегда стартует сақа.
- **Ход:** зажми в нижней трети поля → потяни назад (направление и сила) → отпусти. Физика доигрывает до полной остановки (или до тайм-аута 7 с), затем считаются очки. Короткое оттягивание отменяет бросок без потери попытки.
- **«Выбит»:** асык выбит, когда его **центр** вышел за границу кона. Засчитывается один раз, навсегда (повторных начислений нет).
- **Типы тел:** обычный асык — 10 очков; **золотой** (алтын) — 30; **тяжёлый** (ауыр) — 15, его трудно сдвинуть (в 2,5 раза тяжелее); **камень** (блок) — неподвижное препятствие, его нельзя выбить, от него всё отскакивает.
- **Очки за бросок:** `Σ очков выбитых + 5·(k − 1)` при k ≥ 1 выбитых. Для обычных асыков: 1 → 10, 2 → 25, 3 → 40. В кампании и своих испытаниях +10 за каждую неиспользованную попытку при чистом коне.
- **Звёзды:** 3★ — очистить за *par* бросков или меньше, 2★ — за *par + 1*, 1★ — за любое число доступных бросков.
- **Вдвоём / дуэль с ботом:** общее поле, по 6 бросков у каждого, броски чередуются, очки получает тот, кто выбил асык; побеждает набравший больше, при равенстве — ничья.

**Что упрощено по сравнению с настоящей игрой и почему:** в настоящей игре есть разные виды бросков и правила, связанные с гранями асыка («алшы», «тайкы» и др.), — для короткой браузерной партии оставлена одна понятная механика «выбить из кона». Реальное трение и объём заменены плоской физикой (вид сверху) — прицеливание остаётся точным и одинаковым на всех устройствах. Золотые/тяжёлые асыки и камни — игровая адаптация для разнообразия, а не традиционные правила.

## 3. Что я добавил от себя

- **Свои испытания и вызов другу по ссылке** (без сервера): редактор расстановок (перетаскивание мышью и пальцем, валидация в реальном времени, прилипание к сетке). Поделиться можно только после того, как автор сам прошёл своё испытание — невозможных задач не бывает. Вся расстановка упакована в ссылку ≤ 400 символов (`#c=1.…&s=счёт&n=имя`); друг открывает её и сразу видит экран «Вызов: Аян набрал 85, побей!», после игры — сравнение и «Бросить вызов в ответ». Разбор ссылки строгий, имя и название выводятся только как текст.
- **Особые асыки и вторая глава «Дала»** (уровни 6–10): золотые, тяжёлые, каменные блоки; при первой встрече — короткая подсказка.
- **Бесконечный режим «Бесконечный той»:** волны растут (до 10 асыков), новые типы появляются по ходу, запас бросков, рекорд по очкам и волне, вызов друга на тот же забег.
- **Дуэль с ботом** трёх уровней: бот перебирает ≈ 96 вариантов броска в «невидимой» симуляции той же физики и выбирает лучший с ошибкой исполнения, зависящей от сложности. Бот «целится» видимо и не подвешивает интерфейс.
- **Продолжить раунд после перезагрузки:** после каждого броска состояние раунда сохраняется; после закрытия вкладки в меню есть «Продолжить» с тем же расположением асыков, очками и попытками.
- **Достижения (12), история последних 50 результатов, статистика и график** последних результатов (нарисован кодом).
- **Ежедневное испытание** по дате (одинаковое у всех), серия дней, вызов друга на ту же дату.
- **Косметика и магазин за внутриигровую валюту «тиын»** + тестовый платный набор «Той-Pro» (см. раздел 4).
- Звёзды и *par*; режим сложности «Лёгкий» (длинная направляющая, +1 бросок); вибро-отклик; карточка результата (картинка для отправки).
- Локализация RU / ҚАЗ / EN.
- Псевдообъёмная подача поверх плоской физики: мягкие тени с единым источником света, блики и фаска, вдавленный кон, подпрыгивание при ударе, параллакс из трёх слоёв фона, «камерный толчок». Всё отключается настройкой «Качество» и `prefers-reduced-motion` и **не влияет** на физику и очки (тест `render-isolation`).
- Управление с клавиатуры (стрелки — направление, пробел удерживать — сила, отпустить — бросок), Esc — пауза; тренировочный режим; автопауза при сворачивании вкладки; синтезированный звук.

## 4. Монетизация (демонстрация, реальные платежи отключены)

- **Что получает пользователь.** Тиын зарабатываются игрой: пройденное испытание (10 + 5 за звезду), ежедневное (+10), волны бесконечного режима (+3), достижения. На них покупается **только оформление**: сақа («Күміс», «Алтын», «Оюлы»), площадки («Дала», «Той»), набор асыков «Қызыл».
- **Тестовый набор «Той-Pro»** показывает модель платного дополнения: дополнительная глава из 5 уровней, 2 эксклюзивные сақа и ночная площадка «Түн». Кнопка «Купить (ТЕСТ)» открывает диалог с крупной плашкой «ТЕСТОВЫЙ РЕЖИМ — деньги не списываются»; после подтверждения набор **действительно открывается** (экран «Что вы получили»).
- **Почему это честно.** Ничто из покупаемого не влияет на матч: физика, размеры тел, очки, звёзды и ссылки-вызовы от оформления не зависят (проверено тестом). Pro-уровни — это дополнительный контент, а не преимущество; рекорды локальные, рейтингов нет.
- **Реальные платежи отключены осознанно:** в MVP нет бэкенда и платёжного провайдера, а неработающая кнопка «Купить» по условию задания не засчитывается — поэтому тестовая покупка полностью рабочая, но бесплатная и явно обозначена.

## 5. Как запустить

```bash
npm i
npm run dev      # dev-сервер Vite
npm run build    # проверка типов + сборка в dist/
npm test         # Vitest: правила, уровни, сохранения, физика, кодек ссылок, бот, достижения, магазин
npm run e2e      # Playwright smoke-тест (нужен: npx playwright install chromium)
```

Деплой: репозиторий импортируется в Vercel (Framework preset — Vite; build `npm run build`, output `dist`). Запасной вариант — Netlify с теми же настройками.

## 6. Технологии

| Технология | Зачем |
|---|---|
| TypeScript 5 (strict) | типы ловят ошибки в игровом состоянии, код проще объяснять |
| Vite | мгновенный dev-сервер, `vite build` → статика |
| Phaser 3 | игровой цикл, масштабирование (FIT), отрисовка без внешних ассетов |
| Matter.js (встроен в Phaser) | столкновения полигонов, трение, отскок; та же физика используется ботом «вслепую» |
| HTML + CSS поверх canvas | меню, HUD, модалки, редактор (SVG): быстро стилизуются, текст масштабируется |
| `localStorage` (обёртка с версией схемы и миграцией v1 → v2) | прогресс, рекорды, свои испытания, покупки — без бэкенда |
| URL-хэш + собственный битовый кодек | вызов друга без сервера |
| Web Audio API, Web Share API, Vibration API | звук, «поделиться», вибро-отклик |
| Vitest + Playwright | тесты логики и smoke-тест на реальном рендере |

Архитектура: правила (`rules/`), уровни (`levels/`), кодек ссылок (`challenge/`), магазин (`shop/`) и физический мир (`physics/sim.ts`) — чистый TypeScript без Phaser и DOM; Phaser только рисует и передаёт ввод; UI общается с игрой через типизированный `EventBus`. Функции включаются флагами в `src/config/features.ts`.

## 9. Известные ограничения

- Игра рассчитана на портретную ориентацию; в горизонтальной на телефоне показывается просьба повернуть устройство.
- Казахские тексты требуют проверки носителем языка (помечены `// verify: native speaker`).
- Рекорды и прогресс локальные (на одном устройстве); общего рейтинга нет.
- Ссылка-вызов переносит расстановку с точностью 1 px и 2,8° — то, что видит друг, совпадает с тем, что сохранено у автора.
- На очень слабых устройствах при FPS < 45 качество автоматически переключается на «Низкое».
